# Code of conduct

## The short version

Be decent to people. Assume they are acting in good faith. Criticise code, not the person
who wrote it.

## The longer version

This project welcomes contributions from anyone, regardless of experience, background,
nationality, gender, or which editor they use.

**Expected:**

- Give feedback on the work. "This will break when a category title repeats" is useful;
  "this is sloppy" is not.
- Accept feedback the same way. A review that finds a problem has saved you from shipping
  it.
- Say when you do not know something. It is faster than guessing, and nobody is keeping
  score.
- Remember that most contributors are volunteers doing this after work.

**Not accepted:**

- Harassment, insults, or personal attacks, in issues, pull requests or anywhere else this
  project is discussed.
- Sexualised language or imagery, and unwelcome attention of any kind.
- Publishing someone's private information without their permission.
- Sustained disruption: reopening settled arguments, derailing threads, brigading.

## Enforcement

Maintainers will remove, edit or reject comments, commits, issues and pull requests that
do not follow this document, and will explain why when doing so is useful.

Report a problem privately to the maintainers through
[GitHub Security Advisories](https://github.com/amiranmanesh/tgju-api-go/security/advisories/new),
which is the only private channel this repository has. Reports are handled discreetly.

Consequences scale with the behaviour: a private word, a public warning, a temporary ban,
or a permanent one.
