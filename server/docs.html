TGJU API

Live currency, gold and coin prices, scraped from tgju.org and served as JSON. Every price is quoted in Iranian rial. Every endpoint is a GET.

Quick start

# every board this instance serves
curl -s localhost:8080/v1/markets

# the whole gold board
curl -s localhost:8080/v1/markets/gold

# one instrument, without knowing which board it lives on
curl -s localhost:8080/v1/items/price_dollar_rl

# just the two keys you care about
curl -s 'localhost:8080/v1/markets/currency/items?keys=price_dollar_rl,price_eur'

# only the silver table
curl -s 'localhost:8080/v1/markets/gold?category=%D9%82%DB%8C%D9%85%D8%AA%20%D9%86%D9%82%D8%B1%D9%87'

Response shape

An item carries the site's own rendering next to the parsed number, so you can display one and compute with the other.

{
  "key": "price_dollar_rl",
  "title": "دلار",
  "market": "currency",
  "category": "عنوان",
  "price": { "text": "1,864,000", "value": 1864000 },
  "low":   { "text": "1,860,800", "value": 1860800 },
  "high":  { "text": "1,869,100", "value": 1869100 },
  "change": {
    "status": "low",
    "percent": 0.32,
    "amount": { "text": "6,050", "value": 6050 }
  },
  "time": "11:49:45",
  "profile_url": "https://www.tgju.org/profile/price_dollar_rl"
}

status is low, high or empty, taken from tgju's own classification rather than from the sign of the number: the site renders the change unsigned. percent and change.amount are always positive.

Query parameters

NameMeaning
categoryKeep only the category whose title matches exactly. Titles are Persian; remember to URL-encode.
keysA comma separated list of instrument keys to keep, e.g. keys=geram18,geram24.

Errors

Every failure has the same body and a stable code.

{ "code": "unknown_market", "message": "no such market; see GET /v1/markets", "request_id": "9f2c1a…" }
CodeStatusMeaning
unknown_market404The market in the path is not one this service serves.
not_found404No instrument with that key, or no such endpoint.
upstream_unavailable502tgju.org could not be reached. Worth retrying.
upstream_changed502tgju.org answered with a page this service could not parse. Retrying will not help; the service needs a new release.
rate_limited429Too many requests from your address. See Retry-After.
timeout504The request outlived its deadline.
internal500A bug. The request_id will be in the logs.

Caching

Snapshots are held in memory for a short window and concurrent misses for the same board are collapsed into a single request to tgju.org. Cache-Control on each response reports the remaining window, so a CDN in front of this service can extend the same policy outward.

Compatibility with the original API

/api/price/currency and /api/price/gold return exactly what BlackIQ/tgju-api returned, so an existing client can change one hostname and nothing else. /api/price/coin extends the same shape to coins. New clients should use /v1, which carries the parsed numbers, the change and the timestamp.

Using it as a Go library instead

The same code that backs this service is importable, so a Go service can skip the HTTP hop entirely.

import tgju "github.com/amiranmanesh/tgju-api-go"

client := tgju.New()

snap, err := client.Gold(ctx)
if err != nil {
    return err
}
if item, ok := snap.Lookup("geram18"); ok {
    fmt.Println(item.Title, item.Price.Toman())
}
